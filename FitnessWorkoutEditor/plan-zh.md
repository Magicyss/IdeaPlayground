# 健身跟练视频编辑器 - 详细需求规划文档

## 项目概述

一个纯前端的健身跟练视频编辑器，允许用户导入健身教学视频片段，配置动作参数（次数/时长、组数、休息时间等），最终生成或保存完整的可跟练的健身视频组合。

## 核心问题与解决方案

### 用户痛点
- 健身博主视频只讲解动作，缺少完整跟练视频
- 需要自己计时、数次数，操作繁琐
- 无法根据个人需求组合不同动作

### 解决方案
提供一个可视化工具，让用户自主组合健身动作片段，配置训练参数，生成个性化的跟练视频。

## 第一版功能需求 (V1)

### 1. 视频导入功能 ✅ 已实现
**功能描述：**
- 支持从本地导入视频文件
- 支持常见视频格式：MP4, MOV, AVI, WebM等
- 显示视频预览和基本信息（时长、分辨率等）

**技术实现：**
- 使用HTML5 File API读取本地视频文件
- 使用URL.createObjectURL()创建视频预览
- 使用video元素获取视频元数据

### 2. 视频片段选择功能 ✅ 已实现
**功能描述：**
- 可视化时间轴，显示视频完整时长
- 支持精确选择开始和结束时间点（毫秒级精度）
- 支持通过拖拽或输入时间码（如2:15, 2:30）选择片段
- 实时预览选中的片段
- 支持微调：逐帧前进/后退

**界面元素：**
- 视频播放器
- 时间轴滑块（带双端点）
- 开始时间输入框（格式：MM:SS.SSS 或 HH:MM:SS.SSS）
- 结束时间输入框
- 片段预览播放按钮
- 确认添加按钮

### 3. 动作类型配置 ✅ 已实现

#### 3.1 计次动作（Count-based Exercise）
**适用场景：**深蹲、弓箭步、俯卧撑等可拆分计数的独立动作

**配置参数：**
- **动作名称：** 自定义输入（如"深蹲"）
- **每组次数：** 数字输入（如15次、20次）
- **组数：** 数字输入（如3组）
- **组间休息时间：** 秒数输入（如30秒、60秒）
- **视频片段：** 关联到已选择的视频片段

**执行逻辑：**
- 播放该视频片段N次（N=每组次数）作为一组
- 完成一组后，显示组间休息计时器
- 重复M次（M=组数）

#### 3.2 持续动作（Duration-based Exercise）
**适用场景：**靠墙深蹲、快速高抬腿、平板支撑等按时间持续的动作

**配置参数：**
- **动作名称：** 自定义输入（如"靠墙深蹲"）
- **持续时间：** 秒数输入（如30秒）
- **组数：** 数字输入（如3组）
- **组间休息时间：** 秒数输入（如30秒）
- **视频片段：** 关联到已选择的视频片段

**执行逻辑：**
- 循环播放该视频片段，持续指定时长
- 时间到后显示组间休息计时器
- 重复M次（M=组数）

### 4. 动作间休息时间 ✅ 已实现
**功能描述：**
- 在不同动作之间添加额外的休息时间
- 区别于组间休息，这是换动作时的调整时间

**配置参数：**
- **动作间休息时间：** 秒数输入（如10秒、15秒）

**界面位置：**
- 在动作列表中每个动作项下方显示"动作间休息"设置
- 或在全局设置中统一配置

### 5. 组间休息倒计时功能 ✅ 已实现
**功能描述：**
- 在每组动作完成后，显示休息倒计时界面
- 最后3-5秒播放倒计时音效提醒（Web Audio API 生成 beep 音）
- 显示当前进度（第几组/总共几组）

**界面元素：**
- 大号倒计时数字显示
- 进度条显示剩余时间
- 提示文字："休息中"或"准备下一组"
- 当前进度："第2组/共3组"
- 下一个动作预告（文字）
- 跳过休息按钮

**音效需求：**
- 最后5秒：每秒一次"滴"声
- 最后3秒：每秒一次"滴"声（更高音调）
- 使用Web Audio API动态生成音效

## V1.2 功能需求（播放器增强）

### 1. 运动中提前进入休息功能
**用户场景：**
- 用户在运动过程中可能提前力竭，无法完成设定的次数或时长
- 需要提供一个快速进入休息的选项

**功能描述：**
- 在运动执行界面添加"需要休息"按钮
- 点击后立即暂停当前视频，进入休息倒计时
- 使用配置的组间休息时间

**休息后行为（可配置）：**
用户可在训练计划设置中选择休息后的默认行为：
1. **跳到下一组**（默认）- 休息后直接开始下一组，适合确定无法完成当前组的情况
2. **继续当前组（重试）** - 休息后从当前组的第1次重新开始，适合力竭后需要完整重做
3. **继续当前进度** - 休息后从中断的地方继续（如做了8次就从第9次继续），适合短暂休息

**配置位置：**
- 在训练计划编辑器中添加"提前休息后行为"设置项
- 使用下拉选择或三选一单选框
- 配置保存在训练计划JSON中

**界面元素：**
- 新增"需要休息"按钮（与暂停、跳过并列）
- 按钮图标：💤 或 🛌

### 2. 增强的休息界面

   - 后续版本（V1.5或V2）必须支持视频合成导出功能
   - 使用FFmpeg.js在浏览器中进行视频合成

2. **✅ 倒计时音效：** 使用Web Audio API动态生成beep音效
   - 后续可考虑支持用户自定义音效

3. **✅ 开发优先级：** PC Web端优先
   - PC Web实现后，Pad和手机浏览器基本也能使用
   - 响应式设计，但界面布局以桌面端为主
   - 移动端与PC端的主要区别：
     * 屏幕尺寸和布局适配
     * 触摸操作 vs 鼠标操作
     * 移动端可能需要更大的按钮和更简化的界面
     * 但核心功能完全相同

4. **✅ 账号系统：** V1纯本地化，无需账号
   - 所有数据存储在浏览器本地

5. **✅ 视频文件大小：** 建议单个视频<500MB，避免浏览器性能问题
