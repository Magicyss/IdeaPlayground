# 健身跟练视频编辑器 - 详细需求规划文档

## 项目概述

一个纯前端的健身跟练视频编辑器，允许用户导入健身教学视频片段，配置动作参数（次数/时长、组数、休息时间等），最终生成或保存完整的可跟练的健身视频组合。

## 核心问题与解决方案

### 用户痛点
- 健身博主视频只讲解动作，缺少完整跟练视频
- 需要自己计时、数次数，操作繁琐
- 无法根据个人需求组合不同动作

### 解决方案
提供一个可视化工具，让用户自主组合健身动作片段，配置训练参数，生成个性化的跟练视频。

## 第一版功能需求 (V1)

### 1. 视频导入功能
**功能描述：**
- 支持从本地导入视频文件
- 支持常见视频格式：MP4, MOV, AVI, WebM等
- 显示视频预览和基本信息（时长、分辨率等）

**技术实现：**
- 使用HTML5 File API读取本地视频文件
- 使用URL.createObjectURL()创建视频预览
- 使用video元素获取视频元数据

### 2. 视频片段选择功能
**功能描述：**
- 可视化时间轴，显示视频完整时长
- 支持精确选择开始和结束时间点
- 支持通过拖拽或输入时间码（如2:15, 2:30）选择片段
- 实时预览选中的片段
- 支持微调：逐帧前进/后退

**界面元素：**
- 视频播放器
- 时间轴滑块（带双端点）
- 开始时间输入框（格式：MM:SS或HH:MM:SS）
- 结束时间输入框
- 片段预览播放按钮
- 确认添加按钮

### 3. 动作类型配置

#### 3.1 计次动作（Count-based Exercise）
**适用场景：**深蹲、弓箭步、俯卧撑等可拆分计数的独立动作

**配置参数：**
- **动作名称：** 自定义输入（如"深蹲"）
- **每组次数：** 数字输入（如15次、20次）
- **组数：** 数字输入（如3组）
- **组间休息时间：** 秒数输入（如30秒、60秒）
- **视频片段：** 关联到已选择的视频片段

**执行逻辑：**
- 播放该视频片段N次（N=每组次数）作为一组
- 完成一组后，显示组间休息计时器
- 重复M次（M=组数）

#### 3.2 持续动作（Duration-based Exercise）
**适用场景：**靠墙深蹲、快速高抬腿、平板支撑等按时间持续的动作

**配置参数：**
- **动作名称：** 自定义输入（如"靠墙深蹲"）
- **持续时间：** 秒数输入（如30秒）
- **组数：** 数字输入（如3组）
- **组间休息时间：** 秒数输入（如30秒）
- **视频片段：** 关联到已选择的视频片段

**执行逻辑：**
- 循环播放该视频片段，持续指定时长
- 时间到后显示组间休息计时器
- 重复M次（M=组数）

### 4. 动作间休息时间
**功能描述：**
- 在不同动作之间添加额外的休息时间
- 区别于组间休息，这是换动作时的调整时间

**配置参数：**
- **动作间休息时间：** 秒数输入（如10秒、15秒）

**界面位置：**
- 在动作列表中每个动作项下方显示"动作间休息"设置
- 或在全局设置中统一配置

### 5. 组间休息倒计时功能
**功能描述：**
- 在每组动作完成后，显示休息倒计时界面
- 最后3-5秒播放倒计时音效提醒
- 显示当前进度（第几组/总共几组）

**界面元素：**
- 大号倒计时数字显示
- 进度条显示剩余时间
- 提示文字："休息中"或"准备下一组"
- 当前进度："第2组/共3组"
- 下一个动作预告

**音效需求：**
- 最后5秒：每秒一次"滴"声
- 最后3秒：每秒一次"滴"声（更急促）
- 结束时："开始"提示音
- 使用Web Audio API或预置音频文件

### 6. 训练计划编辑器
**功能描述：**
- 可视化的动作列表，展示所有已添加的动作
- 支持拖拽排序
- 支持编辑每个动作的参数
- 支持删除动作
- 显示总训练时长预估

**界面布局：**
```
[动作1：深蹲]
├─ 视频片段：video1 (2:15-2:30)
├─ 类型：计次
├─ 次数：15次 × 3组
├─ 组间休息：30秒
└─ 动作间休息：15秒
    [↑↓ 拖拽] [编辑] [删除]

[动作2：靠墙深蹲]
├─ 视频片段：video2 (0:05-0:35)
├─ 类型：持续
├─ 时长：30秒 × 3组
├─ 组间休息：30秒
└─ 动作间休息：15秒
    [↑↓ 拖拽] [编辑] [删除]

总时长预估：约8分30秒
```

```

```

格式说明：`视频ID,开始时间,结束时间,次数/时长,组数,组间休息,动作间休息`

### 8. 本地存储方案

**存储位置：**
- 使用浏览器 LocalStorage 存储训练计划JSON数据
- 使用 IndexedDB 存储视频文件引用（不存储实际文件，只存储文件名和路径）

**存储策略：**
- 每次编辑自动保存到草稿
- 支持保存多个命名训练计划
- 训练计划列表显示缩略图和基本信息

**数据持久化：**
- 训练计划数据：LocalStorage（<5MB）
- 大型数据（如视频blob）：IndexedDB
- 支持导出JSON文件到本地
- 支持导入JSON文件恢复训练计划

### 9. 视频导出功能（可选）

**导出方式1：组合数据导出**
- 导出JSON格式的训练计划文件
- 用户下次打开时导入JSON + 重新选择视频文件
- 优点：文件小，速度快
- 缺点：需要保留原始视频文件

**导出方式2：视频合成导出（较复杂）**
- 使用FFmpeg.js或类似库在浏览器中合成视频
- 将所有片段、休息画面、倒计时合成一个完整视频
- 优点：生成独立视频文件，可直接播放
- 缺点：处理耗时长，技术复杂度高

**V1建议：**优先实现导出方式1，视频合成功能作为V2或独立功能

### 10. 训练执行播放器

**功能描述：**
- 根据训练计划自动播放组合视频
- 显示当前进度（第几个动作，第几组）
- 显示剩余时间
- 支持暂停/继续
- 支持跳过当前动作/组

**界面元素：**
- 视频播放区域（全屏或固定比例）
- 进度显示：
  - 当前动作名称
  - 当前组数（第2组/共3组）
  - 当前次数（计次动作时）
  - 剩余时间（持续动作时）
- 总体进度条
- 控制按钮：暂停、继续、跳过、结束

**执行逻辑流程：**
```
1. 播放动作1视频片段 → 循环N次（计次）或循环播放X秒（持续）
2. 显示组间休息倒计时（带音效）
3. 重复步骤1-2，直到完成M组
4. 显示动作间休息倒计时
5. 继续下一个动作
6. 全部完成后显示"训练完成"页面
```

## 技术架构建议

### 前端技术栈
- **框架：** React 或 Vue 3（推荐React，生态更丰富）
- **构建工具：** Vite（快速开发和构建）
- **UI组件库：** Ant Design 或 Material-UI（可选）
- **状态管理：** React Context + useReducer 或 Zustand（轻量级）
- **视频处理：** HTML5 Video API
- **音频处理：** Web Audio API
- **本地存储：** LocalStorage + IndexedDB (使用Dexie.js简化操作)
- **样式方案：** Tailwind CSS 或 CSS Modules

### 部署方案
- **静态网站托管：** GitHub Pages, Vercel, Netlify
- **渐进式Web应用（PWA）：** 添加Service Worker支持离线使用
- **移动端适配：** 响应式设计，支持触摸操作
- **后续转换：**
  - 微信小程序：使用Taro或uni-app重构
  - 移动APP：使用Capacitor或React Native打包

## 用户使用流程

### 完整流程图
```
1. 【开始页面】
   ├─ 新建训练计划
   ├─ 打开已保存的计划
   └─ 导入JSON文件

2. 【训练计划编辑器】
   ├─ 步骤1：导入视频
   │   └─ 点击"导入视频"按钮 → 选择本地视频文件
   │
   ├─ 步骤2：添加动作
   │   ├─ 选择视频片段（时间轴标记开始/结束）
   │   ├─ 选择动作类型（计次/持续）
   │   ├─ 填写动作参数
   │   └─ 添加到训练列表
   │
   ├─ 步骤3：编辑训练列表
   │   ├─ 拖拽调整顺序
   │   ├─ 修改参数
   │   └─ 删除动作
   │
   └─ 步骤4：保存或开始训练
       ├─ 保存训练计划（给计划命名）
       ├─ 导出JSON文件
       └─ 开始训练（进入播放器）

3. 【训练播放器】
   ├─ 自动播放动作视频
   ├─ 显示计次/计时
   ├─ 组间休息倒计时（带音效）
   ├─ 支持暂停/跳过
   └─ 训练完成提示

4. 【训练完成页面】
   ├─ 显示训练统计
   ├─ 返回编辑器
   └─ 保存训练记录（可选功能）
```

## 第二版扩展功能 (V2)

### 1. 在线视频支持
**支持平台：**
- Bilibili（哔哩哔哩）
- 微博视频
- 小红书
- YouTube
- Twitter/X

**技术方案：**
- 使用iframe嵌入（受限于平台政策）
- 或使用平台API获取视频流（需要API密钥）
- 或使用第三方解析服务

**功能实现：**
- 输入视频URL自动识别平台
- 在线预览和片段选择
- 时间码标记（不下载视频）
- 播放时实时加载对应片段

**挑战：**
- 跨域限制（CORS）
- 平台防盗链机制
- 需要网络连接

### 2. 其他V2功能
- 社区分享：分享训练计划给其他用户
- 模板库：预置热门训练计划模板
- 数据统计：记录训练历史和完成情况
- 更多音效和语音提示
- 视频特效：慢动作、画面标注等

## 待确认问题

1. **V1是否需要视频合成导出功能？**
   - 如果需要，建议使用FFmpeg.js，但会增加复杂度和处理时间
   - 如果不需要，只保存JSON配置文件即可

2. **倒计时音效偏好？**
   - 系统提示音（简单）
   - 专业健身音效（需要音频资源）
   - 支持用户自定义音效

3. **是否需要动作视频库？**
   - 内置常见动作示范视频
   - 或完全依赖用户导入

4. **移动端优先还是桌面端优先？**
   - 影响界面设计和交互方式
   - 建议：响应式设计，同时兼顾

5. **是否需要账号系统？**
   - V1可纯本地化，无需账号
   - V2如需云同步，则需要简单的账号系统

6. **视频文件大小限制？**
   - 浏览器处理能力有限
   - 建议：单个视频<500MB，总容量<2GB
